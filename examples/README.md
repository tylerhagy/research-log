 # Example study (fictional)

A complete, made-up study for a grocery delivery app's checkout, showing every record type the skill writes:

- `sessions/2026-03-02-checkout-v2-exploration.md`: solo prototyping that creates two bets
- `sessions/2026-03-04-checkout-dana-session.md`: an interview that adds a belief
- `sessions/2026-03-06-checkout-v3-test.md`: a prototype test with evidence for one bet and against another
- `sessions/2026-03-07-checkout-v3-critique.md`: a stakeholder crit, counted separately from user evidence
- `Decisions.md`: a decision that closes a question and retires a bet
- `Claims.md`: the ledger after all of the above

The people, product and data are all invented.
